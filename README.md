# 🚀 Application of Information & Communication Technology (ICT)

This repository contains course material and training outline for **Application of ICT**, covering modern tools, office automation, programming, and database systems.

---

## 📘 Course Overview

The course is designed to develop practical skills in:

- Office productivity tools  
- Data handling and analysis  
- Web development  
- Database management  
- Modern IT workplace skills  

---

## 📚 Course Contents

### 📝 MS Word – Professional Training
- Document formatting and styling  
- Page layout and design  
- Tables, images, and references  
- Professional report writing  

---

### 📊 MS Excel
- Data entry and cleaning  
- Formulas and functions  
- Charts and data visualization  
- Pivot tables and dashboards  

---

### 🗄️ Databases
- Introduction to databases  
- Relational database concepts  
- SQL basics (CRUD operations)  
- Data storage and retrieval  

---

### 🌐 Web Development (Python Flask)
- HTML & CSS fundamentals  
- Backend development using Flask  
- Routing and templates  
- Form handling and APIs  
- Basic full-stack application development  

---

### 🏢 Advance Office Management
- Digital office tools and workflows  
- Communication systems  
- File and data management  
- Productivity and automation tools  

---

## 🎯 Learning Outcomes

After completing this course, students will be able to:

- Create professional documents and reports  
- Analyze and visualize data using Excel  
- Design and manage databases  
- Build web applications using Flask  
- Apply ICT tools in real-world environments
